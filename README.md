# ElectroAcademy · Contenido publicado

Imágenes **ya aprobadas** para las redes sociales de [ElectroAcademy](https://electroacademy.cl).

Este repositorio es público a propósito: Metricool toma las imágenes desde aquí para programar las publicaciones.

- Cada publicación vive en `publicaciones/<id>/`.
- Solo entra lo que aprobó el fundador. Los borradores, textos y fuentes quedan en el repositorio privado de la Máquina de Marketing.
- Lo sube la herramienta `herramientas/publicar_imagenes.py`. No se edita a mano.
